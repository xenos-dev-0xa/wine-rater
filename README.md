# Vine Rater

A simple Android application for tracking and rating wines.

## Features

- **Wine List**: Browse your collection of wines.
- **Wine Details**: View detailed information about each wine, including vintage, type, rating, and notes.
- **Photo Support**: Add and view photos of your wine bottles.
- **Data Persistence**: Uses Room database to store your wine collection locally.
- **Modern UI**: Built with Jetpack Compose and Material 3.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Local Database**: Room
- **Image Loading**: Coil
- **Architecture**: MVVM (Model-View-ViewModel) with Repository pattern
- **Navigation**: Compose Navigation
- **Camera**: CameraX (for capturing wine photos)

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio (Ladybug or newer recommended).
3. Build and run the app on an emulator or physical device.
